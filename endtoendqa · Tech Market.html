What it does

From spec → running tests

A developer runs /qa-run [feature] and the pipeline autonomously: grooms a KB-seeded test plan, generates exhaustive BE & FE test cases, writes Java automation code via a Codex convergence loop, executes tests against STAGE, files Jira bugs, and optionally runs Gatling perf simulations.

Tech Stack

Key Components

  • BE Automation: Java 15 + RestAssured + TestNG + Allure
  • FE Automation: Java 15 + Playwright + TestNG + CSV-driven data
  • Knowledge Graph: Neo4j (371 nodes, 3863 edges)
  • Submodules: BE_Automation + fe-automation (independent CI)
  • Code review agent: Claude ↔ Codex autonomous loop
  • Bug filing: qa-jira-log with fingerprint dedup
Invocation

Main Commands

Cost optimisation techniques in use

  • Neo4j graph replaces full file scan (60% token savings on exploration)
  • Change-scoped groom: only touches modified paths by default
  • BE max / FE medium split: saves ~40k on low-signal FE permutations
  • Convergence gate = 0 CRIT/MAJOR × 2 rounds, not exhaustive rounds
  • SPEC-ONLY flag skips graph traversal when KB not needed
  • Dry-run gate on Jira filing prevents double-spend on re-runs

Architecture Patterns I Established

BE Pattern

SOLID Automation Classes

Each feature gets dedicated provisioner + test class hierarchy. Shared fixtures via getOrCreate pattern. DTO-typed responses, no bare assertNotNull. @AfterMethod cleanup, never try/finally in tests.

FE Pattern

Page Object + CSV-Driven

CSV row = one test. dependsOnMethods chains must re-navigate themselves (page state doesn't carry). Playwright locators target data-testid. FE compiles against BE jar.

Data Strategy

Dynamic Date Seeding

All time-sensitive fixtures offset from LocalDate.now(). Fixed the static-date collision bug that caused parallel run failures in TimeOff suite.

Defect Pattern

Known-Defect Tagging

Reproducing a tracked defect must fail the test, not pass it. Defect tests tagged [Negative] [BUG - reason] TC-NNN for traceability.

Pipeline Additions After My Work

Infrastructure and pipeline enhancements built on top of the test automation foundation.

Phase 1 Enhancement
qa-groom — KB-Grounded Seed
Neo4j code-graph + repos/ source traversal + oracle error codes. Change-scoped by default. --full, --monkey, --push flags. Seeds the QA oracle that all downstream phases trust.
Phase 3.1
qa-rag — RAG over KB
Semantic search over the grounded knowledge base. Feeds fixture readiness checks and plan generation with existing test context.
Phase 3.3
Fixture Readiness Check
Validates that all required fixtures (users, entities, configs) exist on STAGE before spending tokens on codegen. Blocks early.
Phase 3.5 — Opt-in
Adversarial Monkey Sweep
LIVE STAGE mutations testing boundary conditions. OVER_ACCEPT findings → [PRODUCT-FINDING]. VALIDATION_GAP → test robustness. Opt-in via --monkey because STAGE side-effects are not always reversible.
Phase 3/Phase 8 Gates
Testid Gate System (Gate 1 + Gate 2)
Gate 1: static lint before any FE codegen. Checks testid-required.json list against the contract-web codebase. Gate 2: DOM probe before FE main codegen. Both emit-and-block by default. Missing testids → contract-web-testid-fixer raises MR but never self-merges.
Phase 6
Split BE/FE Case Generation
BE = max effort (exhaustive API permutations). FE = medium (persona journeys + monkey paths). Separate CSV outputs. BE CSV generated first because FE arrange layer uses BE Provisioner helpers.
Phase 6.1 — Opt-in
Codex Convergence Loop
Autonomous Claude ↔ Codex code review loop. Convergence = 0 CRIT/MAJOR findings × 2 consecutive rounds, or MAX_ROUNDS (default 4). Each round: Claude reviews → Codex fixes → Claude re-reviews. No human bottleneck.
Phase 7 Enhancement
BE Design-Doc Template
Structured design doc generated before BE codegen. Forces agent to think through data flow, error paths, and fixture dependencies before writing test code.
Phase 7 Enhancement
FE Red-Green Learnings
Codified lessons from failed FE test runs fed back into the codegen rule. Prevents recurring Playwright locator bugs, timing issues, and page-state assumptions.
Phase 10.1
Codex Post-Execution Verify
After test run, Codex reviews failure logs and proposes fixes for flaky/environment issues vs real bugs. Feeds qa-jira-log with classified failures.
Phase 11
qa-jira-log — Automated Bug Filing
Fingerprint-based dedup (label qa-fp-{hash}) prevents duplicate tickets. Dry-run gate shows diffs before filing. Back-links test markers to Jira issues. Structured priority/severity from failure classification.
Phase 12 — Opt-in
Gatling Performance Simulations
Auto-generates Gatling Scala simulations from BE test patterns. Gate = 0 failures. ~115 existing simulations. Skip via --no-perf.
Cross-cutting
code-review-graph MCP — Neo4j Knowledge Graph
371 nodes, 3863 edges, 58 files. Tools: semantic_search_nodes, get_impact_radius, query_graph, detect_changes, get_affected_flows. 60% token savings vs file scanning. Auto-updates on file changes via hooks.
Cross-cutting
Flow-Capture Contract
DevTools recording → {feature}-flow-capture.json + testid-required.json + screens-manifest.json. Feeds testid gates and plan generation. Replaces manual screen analysis.
Cross-cutting
qa-copy-check — UI Language QA
Persona-aware copy/language QA. Vision checks by reading PNGs directly (no external API). Capture → judge → report lane. Catches tone mismatches, truncation, missing translations.

What Can Still Improve

Honest assessment of gaps, rough edges, and open opportunities.

Opportunity

STAGE Environment Stability

STAGE is shared; payroll tagging was non-functional for weeks (confirmed 2026-07-16). Tests depend on live STAGE state but have no circuit-breaker. Solution: environment health probe as Phase 0 gate; auto-quarantine env-blocked tests vs real failures.

Opportunity

FE Coverage Gap

FE automation at medium effort means some edge-case permutations are intentionally skipped. Over time, monkey sweep findings that become regression risks aren't automatically promoted to the FE CSV. Need a promotion mechanism from PRODUCT-FINDING → test case.

Opportunity

Submodule Sync Friction

BE_Automation and fe-automation are submodules with independent CI. Parent repo doesn't know submodule test results without explicit pointer updates. CI dashboards for parent and submodules are separate. Unified status page would help.

Opportunity

Codex Loop MAX_ROUNDS Cap

At MAX_ROUNDS=4 with CRIT findings still open, the loop exits and humans must intervene. There's no escalation path — it just stops. Should emit a structured handoff ticket with exactly which findings remain open and why they didn't converge.

Opportunity

contract-web-testid-fixer MR Latency

Fixer raises MR but never self-merges (by design). This creates a bottleneck: FE codegen is blocked until a human merges the testid MR. For high-velocity feature branches, this can stall the pipeline for hours.

Opportunity

Neo4j Graph Coverage

KB covers code structure but has gaps: cascades, some error codes, and newer operations not yet in graph. qa-groom notes these as KB-GAP. Currently requires manual gap-filling. Should auto-detect via diff against spec.

Opportunity

Dynamic Fixture Resolution at Scale

Fixtures resolved via API/shared CSV providers work but add runtime latency. For large parallel test suites, fixture contention (same entity mutated by two tests) is unresolved. Lock + claim mechanism needed.

Opportunity

Gatling Coverage Automation

~115 Gatling simulations exist but coverage is uneven. Phase 12 generates new ones but doesn't track which endpoints have zero perf coverage. Endpoint → simulation coverage map would prioritize what to generate next.

Already Solved (Notable Wins)

Solved

Static Date Collision in Parallel Runs

TimeOff tests used hardcoded dates; parallel runs collided on same entity. Fixed with LocalDate.now()-based seeding with per-test offsets.

Solved

Signed URL Re-encoding

RestAssured's default URL re-encoding broke pre-signed GCS/S3 URLs. Fixed with urlEncodingEnabled(false).

Solved

Duplicate Jira Filing

Re-runs would file duplicate bugs. Fixed with fingerprint label dedup: each failure gets a stable qa-fp-{hash} label; Jira search before filing.

Solved

FE Page State Propagation Bug

Split-test dependents assumed previous test left page in correct state. Codified rule: every dependsOnMethods chain must re-navigate itself.
